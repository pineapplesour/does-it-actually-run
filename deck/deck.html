04
핵심 발견 · THE KEY MOMENT

추측을 측정으로 바꾸자 전부 통과했습니다
We replaced one assumption with a measurement

BEFORE  가정: "root 권한, 네트워크 자유"     assumed root + open network
        Round 1 → 0/3 FAIL   (apt: Permission denied / httpbin: Connection reset)
        Round 2 → 3/3 PASS   자가수정 루프가 복구 self-repair loop recovered

AFTER   측정: uid=1001, sudo=passwordless, arbitrary_http_egress=blocked
        Round 1 → 3/3 PASS   재시도 없음 · 신뢰도 1.0   no retry needed
에이전트에게 진실을 주면 처음부터 맞춥니다.
Give the agent measured truth and it gets it right the first time.
